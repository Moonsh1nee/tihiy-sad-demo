- Повреждённый localStorage и неизвестные товары, подставленная цена не используется.
- Отказ чтения Storage API и QuotaExceededError при записи: весь путь работает в памяти вкладки, посетитель видит объяснение.
- Прямое открытие и обновление `/bouquets/01/`, `/bouquets/07/`, `/delivery/`, `/workshop/`; галерея «букет в руках», загрузка изображений, noindex, manifest с подпапкой, настоящая HTTP 404 и возврат в каталог.

Проверяется отсутствие ошибок JavaScript и неожиданных HTTP 4xx/5xx на основном покупательском пути. Проверено, что введённые имена, адрес и поздравление не попадают в localStorage. Clipboard API, аналитика, серверная отправка данных и платёжные SDK не используются.

## Исправления по результатам проверки

- Статический экспорт Next.js 16 на Windows создавал вложенные файлы RSC-сегментов при запросе клиентом dotted-имён. `postbuild` добавляет соответствующие файлы в сам `out`; статический сервер не маскирует проблему.
- Фильтры получили явные доступные имена; тесты находят их через accessible label.
- Исправлены мобильный перенос заголовка и композиция подвала, увеличен кегль вспомогательных текстов.
- Escape возвращает фокус на кнопку меню. Отказ хранилища не прерывает оформление. Для миниатюр и корзины указаны собственные `sizes`.
