# Тихий сад

Вымышленная авторская мастерская в Волгограде. Задача — дать посетителю выбрать цветы и пройти полный демонстрационный покупательский путь без отправки персональных данных и без оплаты.

## Визуальное решение

- Молочный #F8F5EF, сливовый #472638, пыльно-розовый #E9DBDC, мягкий розовый #F0E6E5, зелёный #596B4C.
- Cormorant Garamond для заголовков и Manrope для интерфейса, локальные WOFF2 с кириллицей.
- Редакционный первый экран: крупная типографика слева, предметная фотография справа. На телефоне — последовательное чтение и большая фотография.
- Ассиметрия в подборке главной; спокойная регулярная сетка в каталоге для сравнения товаров.
- Фотографии — единая авторская серия; никаких внешних изображений, отзывов и вымышленных контактов.

## Реализация

1. 12 букетов с индивидуальным составом; для 01 и 07 дополнительные ракурсы и фото в руках. Оптимизированные WebP трёх размеров.
2. Next.js App Router и статические маршруты; чистые функции каталога, вариантов, корзины и формы отдельно от компонентов.
3. Корзина через useSyncExternalStore. В localStorage только разрешённые товарные поля; защищённое восстановление и режим работы без хранилища.
4. Оформление: данные → проверка состава → явное завершение демонстрации. Данные формы только в React state, затем очищаются.
5. Vitest и Playwright на production out в подпапке; GitHub Actions публикует только после проверок.

## Границы

Избранное действует в памяти приложения до перезагрузки, включая переходы в карточку букета и обратно; в localStorage по-прежнему сохраняется только корзина. Реальный backend, персональные данные, платёжные интеграции и уведомления не подключены. Публикация на GitHub требует отдельного разрешения владельца.

## Уточнение по референсам, 2 ноября 2026

Пользователь разрешил сразу менять локальный сайт и отверг результат генерации макета в Figma. Ориентиры: светлый полноэкранный первый экран и компактная навигация из Flower Website, бордовые подборки на светлом розовом фоне из PETAL / POST, организация каталога Flowwow. Первая короткая Pinterest-ссылка возвращала ошибку. Figma просмотрена в браузере без входа и без правок; MCP-чтение ограничено квотой плана.

- Главная: собственный новый светлый кадр hero-v3, тёмная типографика, плавающая молочная навигация, насыщенная бордовая подборка с тремя букетами.
- Каталог: четыре колонки на широком экране, две на телефоне, быстрые категории по поводу, поиск по названию/составу, видимые цены, отдельная карточка ShopCard и избранное.
- `redesign.css` изолирует визуальные изменения; чистые функции расчётов, восстановление корзины и сценарий оформления не переписывались.
